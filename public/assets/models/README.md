# /public/assets/models

glTF (`.glb` / `.gltf`) の3Dモデルを配置するディレクトリです。
ここに置いたファイルはビルド時にコードへ埋め込まれず、`GLTFLoader` が
実行時に `fetch` して読み込みます。

現在の実装 (`src/components/Scene.jsx`) が参照しているファイル名:

- `player.glb` — プレイヤーモデル（画面左側に配置）
- `boss.glb` — ボスモデル（画面右側に配置、プレイヤーと向かい合う）

ファイルが存在しない間は、読み込みエラーを`ModelLoadBoundary`が捕捉し、
それぞれ赤（プレイヤー）・青（ボス）のワイヤーフレームのプレースホルダーが
代わりに表示されます。上記のファイル名でこのディレクトリに置くだけで、
自動的にモデルが表示されます。
