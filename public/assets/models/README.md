# /public/assets/models

glTF (`.glb`) の3Dモデルを配置するディレクトリです。
ここに置いたファイルはコードへ埋め込まれず、`GLTFLoader` が実行時に
`fetch` して読み込みます。

現在の実装 (`src/game/FuriDuel.jsx`) が参照しているファイル名:

- `player.glb` — プレイヤーモデル
- `boss.glb` — ボスモデル

読み込みに失敗した場合は、それぞれ簡易的な代替形状
（プレイヤー: 発光する円錐、ボス: 発光する多面体）を表示してゲーム自体は
継続できるようにフォールバックします。
